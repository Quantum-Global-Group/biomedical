First-in-class APOL1 inhibitor in Phase III for APOL1-mediated kidney disease. Connects HTN-attributed ESKD, lupus nephritis, and sickle cell nephropathy via the APOL1 G1/G2 risk genotype enriched in African ancestry.

Read top-to-bottom: investigation parameters define what you're asking, candidate context says why this compound is worth asking about, run path determines which algorithms execute, live KG preview shows what the model will see before compute, evidence posture guarantees the integrity guards are on, and session persists the snapshot so the contract is reproducible.

02Candidate Contextreactive · curated + derived
PROVIDES
✓For curated candidates (Inaxaplin, Venetoclax, Empagliflozin, Decitabine, etc.): description, primary target list, FDA status with year, indications, active trials, repurposing focus

✓For non-curated compounds: derived fallback with empty-field markers and "derived from Hetionet base record" footer
INTERROGATE
⊙Is the compound FDA-approved for this indication, or strictly investigational? An investigational compound carries a different evidence bar
⊙Is there an equity/ancestry caveat that the trial-evidence axis on Validate cannot answer?
⊙Does the description match your mental model of the drug, or are you trusting the compound by name only?

PROVIDES

05Evidence Posture · Integrity Guards23 guards · 6 categories · live status
PROVIDES
