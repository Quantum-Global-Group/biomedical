⊙ HOW TO READ THIS PAGE
What this view answers — and what to question

The Experiment page is what your investigation produced. It pulls the configuration from Initialize and renders five tools: source check for provenance, model leaderboard for which algorithm won, detailed metrics for the top model's full diagnostic profile, candidate spotlight for the selected compound's prediction probability, and quality controls for whether the engineering passed the audit. Every section is reactive — change the candidate, run path, or any guard on Initialize and watch this page recompute.

01Source Checkprovenance · 4 upstream services
PROVIDES
✓API status (latency, HTTP code), latest run ID, candidate source file, and quantum job source — all four labelled live or fallback
✓Stale-data detection: anything older than the latest job is flagged before you can read its numbers
INTERROGATE
⊙Is any source labelled fallback? Treat those numbers with extra skepticism — the upstream pipeline didn't reach
⊙Is the latency healthy (<100ms), and is the API code 200? A degraded API may be silently throttling shots
02Model LeaderboardPR-AUC · live algorithms in current run path
PROVIDES
✓Every live algorithm in the chosen run path, ranked by PR-AUC on the same hard-negative test set
✓Parameter count column — visible because parameter-efficiency, not raw advantage, is this project's claim
✓Δ vs best classical and full param ratio (e.g. 16 / 18,000) summarized below the table
INTERROGATE
⊙Is the quantum delta over classical within CV variance? If so, lead with parameter-efficiency, not raw advantage
⊙Are all rows labelled LIVE? A FALLBACK row contributing to the top-3 invalidates the comparison
⊙Did the run path you chose actually have the algorithms you needed? Switch path on Initialize and watch the leaderboard rebuild
03Detailed MetricsPR-AUC + ROC + F1 + Brier + per-fold variance
PROVIDES
✓For the top model: PR-AUC, ROC-AUC, F1, Brier (calibration), Matthews correlation, and bootstrap 95% CIs
✓Per-fold PR-AUC bars showing variance across the 5 stratified CV folds
INTERROGATE
⊙Is the CV variance high (folds spread > 0.04)? If yes, the headline number is fragile
⊙Is the Brier score < 0.10? Higher means calibration is off — predicted probabilities aren't actual probabilities
04Candidate Spotlightprediction probability for the selected pair
PROVIDES
✓The selected compound's predicted probability against the disease (this is a per-pair score, distinct from the model's PR-AUC)
✓Three numbered reasons explaining why the candidate surfaced (KG path score, kernel separation, equity weighting)
✓Top 6 candidate–disease pairs ranked, with confidence tier (High / Medium / Low) — click any to make it primary
INTERROGATE
⊙Does the prediction probability match the reasoning? A 0.91 score with thin KG evidence is a red flag
⊙Are the runner-up candidates within ±0.02 of the top? If so, the ranking is not robust
05Scientific Quality Controlsaudit · derived from integrity guards
PROVIDES
✓Pass / fail status on every integrity guard from Initialize — same data source, rolled up into an audit table
✓Total passed / total checks summary; failed critical guard turns the audit FAILED
INTERROGATE
⊙Did any QC tile fail? A failed critical tile invalidates everything above it on this page
⊙If a recommended guard failed, can the gap be mentioned as a limitation in the report?
